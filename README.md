# Christmas TV

Miki & Saki のクリスマス画面です。静的な HTML・CSS・JavaScript と同梱音源で動きます。

公開先: https://nuju.github.io/christmas-tv/

この説明は、このブランチの機能を記載しています。公開サイトへの反映は、公開用の
`main` ブランチへの取り込みと GitHub Pages の更新後です。

## テレビのリモコンで操作する

1. 最初は **Play music** が選ばれています。決定で再生・停止します。
2. 再生ボタンのある段で **左右** を押すと、前後の曲へ切り替わります。
3. **下** を押すと **全画面** に移動します。決定で全画面表示を開始・終了します。
4. 全画面ボタンから **右** を押すと **音声：AAC / MP3** に移動します。
   決定で音声形式を切り替えます。**上** で再生ボタンに戻ります。

マウスやタッチでも各ボタンを使えます。パソコンでは、操作ボタンにフォーカスが
あるときの F キーでも全画面を切り替えられます。

音楽の再生中、またはページの全画面表示中は、8秒操作しないと操作部と案内が隠れます。
曲名・作者・ライセンスは残ります。隠れているときの最初の決定／Space は表示の復帰に
使うため、音楽が急に止まったり、全画面が解除されたりしません。

## 音が乱れる場合

この版は、従来の MP3 に加え、別の復号方式を使う AAC-LC を用意しています。
初回はブラウザーが対応を申告する場合に AAC を選び、非対応なら MP3 を選びます。
どちらも元ファイルから音量を下げ、画像や古い付加情報を除いて作り直した音源です。
約20分の Wish Background は配信容量を抑えるため、両形式とも80 kbpsにしています。
追加2曲は AAC 128 kbps／MP3 160 kbpsです。圧縮による音質の変化はありますが、
元の音源もリポジトリに残しています。

再生自体はできるのにノイズが聞こえる場合は、**音声：AAC / MP3** を切り替えてください。
同じ曲の再生位置と再生・停止状態を、ブラウザーが対応する範囲で維持します。
手動で選んだ形式は保存可能なブラウザーでは次回も使います。

ブラウザーが復号エラーや形式非対応を通知した場合は、対応を申告している別形式を
一度だけ試します。通信エラーや再生許可の拒否では、案内を表示します。
音声形式への対応確認だけで、テレビの実際の音質までは判定できません。

元の3音源と、この版の6音源は全編デコードに成功しています。ただし、
**Panasonic TH-43LF2 の実機でノイズが解消することは未確認です。**
音声の変換は互換性を改善するための対策であり、原因を確定した修理ではありません。

## 全画面表示の対応範囲

標準の Fullscreen API と WebKit・Mozilla・Microsoft の旧形式に対応しています。
ボタンはクリックまたは決定操作から全画面を要求し、実際の状態に応じて表示を更新します。
テレビやブラウザー側の終了操作にも追従します。音声が再生できなくても全画面ボタンは使えます。

ページからの全画面表示に対応していないブラウザーや、利用が許可されていない環境では、
その旨を表示します。ページの大きさは通常時もブラウザー内の表示領域全体ですが、
非対応環境のアドレスバーなどをページから強制的に消すことはできません。
ブラウザー自身に全画面の項目がある場合は、そちらを使用してください。

参考:

- [WHATWG Fullscreen API](https://fullscreen.spec.whatwg.org/)
- [Panasonic TH-43LF2 操作ガイド：画面の設定をする](https://av.jpn.support.panasonic.com/support/tv/em/th_43lf2_em_files/part416.htm)
  （インターネット利用中はオーバースキャンを設定できない旨を記載）

## 開発と確認

表示するためのビルドや外部ライブラリーは不要です。JavaScript は旧テレビ向けの ES5 で記述し、
雪は40個に抑えています。動きを減らす設定をしている端末では雪を表示しません。

Python 3 と FFmpeg がある環境で音声を再生成できます。元の音源は変更しません。

```sh
python3 scripts/prepare-tv-audio.py
```

ブラウザーの確認には Node.js、Playwright と Chromium を使用します。既存の環境に
Playwright があれば、次のコマンドでローカル HTTP サーバーを起動して検証します。
サーバーは検証の終了時に閉じます。

```sh
node tests/browser-smoke.cjs
```

別途用意した Chromium の実行ファイルは `BROWSER_EXECUTABLE`、画面の保存先は
`CHRISTMAS_SCREENSHOT_DIR` で指定できます。
検証には3曲×2形式の実再生、繰り返し、選曲、形式の変更、失敗時の復帰、全画面、
リモコン操作、操作部の自動非表示を含みます。テレビ実機の確認を代替するものではありません。
